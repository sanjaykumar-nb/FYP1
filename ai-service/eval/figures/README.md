## Design constraints applied

- **Canvas units are points.** All four are 516pt wide = 7.17in = full IEEE two-column
  text width. Use `figure*` (starred) environments. Label text is 7–9pt, i.e. legible at
  final printed size without scaling.
- **No titles inside the figures** — IEEE captions sit below; an internal title would
  duplicate the caption.
- **Palette validated, not eyeballed.** `#1a5490 / #d2691e / #6a4c93` passes all six
  checks of the dataviz validator (worst adjacent CVD ΔE 23.7 protan). A blue/red/green
  candidate was rejected — it failed at protan ΔE 3.4.
- **Grayscale-safe.** Blue vs purple collapse in grayscale (ΔL 0.018), so Fig. 3 carries
  45°/135° hatch patterns *and* direct value labels as secondary encoding. Figs. 2 and 4
  use blue+orange only (ΔL 0.153, safe in B&W). Fig. 2 additionally distinguishes series
  by marker shape (circle vs square).

## Converting for LaTeX

IEEE submission systems generally want PDF/EPS rather than SVG:

```bash
# any one of these
inkscape fig2_token_scaling.svg --export-type=pdf --export-filename=fig2.pdf
rsvg-convert -f pdf -o fig2.pdf fig2_token_scaling.svg
cairosvg fig2_token_scaling.svg -o fig2.pdf
```

Alternatively keep SVG and use `\usepackage{svg}` with `\includesvg{}` (requires
`--shell-escape` and Inkscape on the build machine).

composite logistic model tuned on the other 9 projects. The story-point baseline is measured
on all 987 sprints. Recall 1.000 with precision 0.552 places the rule as a
high-sensitivity early warning rather than a precise classifier.}
\label{fig:holdout}
\end{figure*}

\begin{figure*}[t]

\includegraphics[width=\textwidth]{fig4_ablation.pdf}

deliberately configured in the naive path's favour --- small projects, full context in a
single call, and lenient response parsing --- so this is a floor on the graph
architecture's relative standing.}

\end{figure*}
